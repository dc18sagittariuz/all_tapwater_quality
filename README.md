# สถิติคุณภาพน้ำประปาย้อนหลัง

หน้า dashboard สรุปผลตรวจคุณภาพน้ำประปาจากไฟล์ `เคมีใหญ่.xlsx` เทียบกับเกณฑ์กำหนดคุณภาพน้ำประปา การประปานครหลวง (ประกาศ ณ วันที่ 11 ตุลาคม 2565)

- ภาพรวมจำนวนตัวอย่าง สถานที่ ช่วงวันที่ และจำนวนผลที่ไม่เป็นไปตามเกณฑ์
- ตัวกรองช่วงวันที่ ประเภทงาน สาขา และติ๊กเลือกสถานที่ได้สูงสุด 8 แห่งเพื่อเปรียบเทียบ (เส้นคนละสี)
- กราฟค่าเฉลี่ยรายเดือน เลือกได้สูงสุด 6 พารามิเตอร์ แสดงแบบแยกกราฟ หรือรวมเป็นกราฟเดียว (แกน Y เป็น % ของเกณฑ์, ค่าจริงแบบ log หรือค่าจริงแบบปกติ)
- ตารางสถิติรายพารามิเตอร์ (จำนวนผล ต่ำสุด มัธยฐาน เฉลี่ย สูงสุด เกณฑ์ จำนวนที่ไม่ผ่าน)
- ปุ่มส่งออกสรุปหนึ่งหน้าเป็นรูป PNG ขนาด A4 ตามตัวกรองที่เลือก
- ตัวกรองที่เลือกจะถูกเก็บไว้ในลิงก์ (หลังเครื่องหมาย `#`) คัดลอกลิงก์ไปส่งต่อได้เลย คนที่เปิดจะเห็นมุมมองเดียวกัน

เป็นหน้าเว็บแบบ static ล้วน ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ทำงานบนเบราว์เซอร์ทั้งหมด

## โครงสร้างไฟล์

```
index.html          หน้าเว็บ (โครงหน้า สไตล์ และสีทั้งโหมดสว่าง/มืด)
app.js              การคำนวณสถิติ กราฟ และการส่งออกรูป
dash.js             ตัวโหลดข้อมูล เก็บสถานะตัวกรอง และสั่งวาดใหม่
data/samples.json   ผลตรวจทั้งหมด (สร้างจาก Excel ด้วย scripts/clean.py)
data/criteria.json  รายการพารามิเตอร์ หน่วย และเกณฑ์
vendor/d3.min.js    ไลบรารีกราฟ D3 v7.9.2 (สัญญาอนุญาต ISC ดู vendor/LICENSE-d3.txt)
scripts/clean.py    สคริปต์แปลง เคมีใหญ่.xlsx เป็นไฟล์ใน data/
```

## ขึ้น GitHub Pages

1. สร้างรีโปใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ราก (root) ของรีโป ให้ `index.html` อยู่ชั้นบนสุด
   (หน้าเว็บ: **Add file → Upload files** แล้วลากทั้งโฟลเดอร์ หรือใช้ `git push`)
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment → Source** เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)` กด **Save**
5. รอประมาณ 1–2 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโป>/`

### เรื่องการมองเห็นข้อมูล

หน้า GitHub Pages เปิดดูได้ทุกคนบนอินเทอร์เน็ต รวมถึงไฟล์ `data/samples.json` ที่มีชื่อสถานที่เก็บตัวอย่างทั้งหมด

- บัญชีฟรีใช้ Pages ได้กับรีโปแบบ public เท่านั้น
- รีโปแบบ private ใช้ Pages ได้เมื่อเป็นแผน GitHub Pro / Team / Enterprise แต่หน้าเว็บก็ยังเปิดได้สาธารณะ
- การจำกัดให้ดูได้เฉพาะคนที่มีสิทธิ์ในรีโป ทำได้เฉพาะ GitHub Enterprise Cloud

ถ้าข้อมูลนี้ไม่ควรเผยแพร่ ให้ตรวจกับหน่วยงานก่อนเปิด Pages

## เปิดดูในเครื่อง

เปิด `index.html` โดยดับเบิลคลิกจะโหลดข้อมูลไม่ได้ เพราะเบราว์เซอร์บล็อกการอ่านไฟล์ JSON จาก `file://` ให้เปิดผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ แทน:

```bash
cd โฟลเดอร์นี้
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

## อัปเดตข้อมูล

เมื่อมีผลตรวจใหม่ใน `เคมีใหญ่.xlsx`:

```bash
pip install openpyxl
python scripts/clean.py "เคมีใหญ่.xlsx" data/samples.json data/criteria.json
```

แล้ว commit / อัปโหลดไฟล์ `data/samples.json` และ `data/criteria.json` ขึ้นรีโป หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที

ข้อควรรู้:

- สคริปต์อ่านแผ่นงานแรก และอ้างอิงคอลัมน์ตามตำแหน่ง (เช่น คอลัมน์ L = คลอรีนอิสระคงเหลือ) ถ้าไฟล์ Excel มีการเพิ่ม ลบ หรือสลับคอลัมน์ ต้องแก้ตัวเลขคอลัมน์ในรายการ `P` ของ `scripts/clean.py` ก่อน
- ค่าที่เป็น `ND` เก็บเป็น `ND`, ค่า “น้อยกว่า x” หรือ “< x” เก็บเป็น `<x`, ค่า “มากกว่า x” เก็บเป็น `>x` ถ้าเจอข้อความรูปแบบอื่น สคริปต์จะหยุดและแจ้งค่าที่อ่านไม่ได้
- ถ้าเกณฑ์เปลี่ยน ให้แก้ค่า `lo` (ขีดล่าง) และ `hi` (ขีดบน) ในรายการ `P` ของ `scripts/clean.py` แล้วรันใหม่ อย่าแก้ `data/criteria.json` ด้วยมือ เพราะจะถูกเขียนทับเมื่อรันสคริปต์ครั้งถัดไป

## วิธีคำนวณ

- ต่ำสุด มัธยฐาน เฉลี่ย สูงสุด คำนวณจากผลที่รายงานเป็นตัวเลขเท่านั้น ผล ND และ “น้อยกว่า” นับแยกในคอลัมน์ “ต่ำกว่าขีดวัด / ไม่พบ”
- เกณฑ์ปี 2565 ใช้เทียบกับผลทุกปี รวมถึงปีก่อนประกาศ
- หน่วยมาจากประกาศเกณฑ์ ไฟล์ต้นทางไม่ระบุหน่วย สารละลายเทียบกับเกณฑ์ TDS และสารไตรฮาโลมีเทนเทียบกับเกณฑ์ผลรวมอัตราส่วน (≤ 1) ซึ่งเป็นข้อสันนิษฐาน
